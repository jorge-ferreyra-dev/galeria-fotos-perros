# Titulo del proyecto

Galería de fotos de perros.

## Objetivo

Galería de fotos diseñada con el objetivo de practicar Grid, Flexbox, y explorar el manejo de colores con HSL. Como así tambien implementar un layout responsive profesional, combinando las técnicas de CSS moderno.

## Descripción

En el proyecto se implemento HTML semántico para el index.html y en styles.css se estilizo la pagina con el uso de flexbox, css gris , se estableció variables para  paletas de colores y espaciados, e investigación sobre HSL por ultimo media queries para tablet y celular.
